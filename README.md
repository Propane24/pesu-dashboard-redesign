# PESU Dashboard Redesign

> A modern redesign of the PES University dashboard focused on improving usability, accessibility, and visual consistency.

## Overview

The existing PESU dashboard works well functionally, but its interface feels outdated and cluttered. This project reimagines the dashboard with a cleaner layout, improved navigation, and a more intuitive user experience while preserving the core functionality students rely on.

## Features

- 🎨 Modern and minimal UI

## Design Goals

- Reduce visual clutter
- Make frequently used actions easier to access
- Improve accessibility through better typography and contrast
- Create a consistent design language across pages
